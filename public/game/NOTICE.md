# About the images in this folder

These images are artwork from **Star Wars: Galactic Racer**: ability glyphs, stat glyphs and part card art. They are not
ours. They belong to their respective owners (Lucasfilm Ltd., Disney, Fuse Games and the game's publisher) and are shown
here only to identify the game's items in an unofficial fan tool. This project is not affiliated with or endorsed by them.

They were downloaded, shrunk and converted by `scripts/fetch-icons.mjs` from the public game database at
https://galacticracer.gameslantern.com.

**To remove them:** set `USE_GAME_ART` to `false` in `src/lib/game-art.ts` (the site falls back to original icons),
then delete this folder. If you are a rights holder and want them taken down, open an issue on the project's GitHub page.
